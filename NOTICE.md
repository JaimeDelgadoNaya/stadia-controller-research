# Credits and provenance / Créditos y procedencia

## English

This project builds on GaryOderNichts' StadiaController research and the original
Google controller updater preserved by ChristopherKlay and StadiaMemories.
Protocol descriptions, original methods and constants should be credited to those
projects. The new scripts are independently written research tooling.

- [GaryOderNichts/StadiaController](https://github.com/GaryOderNichts/StadiaController)
- [Original research post](https://garyodernichts.blogspot.com/2023/01/looking-into-stadia-controller.html)
- [ChristopherKlay/stadiacontroller](https://github.com/ChristopherKlay/stadiacontroller)
- [StadiaMemories/firmware](https://github.com/StadiaMemories/firmware)
- [NXP HAB RVT structure and wrappers](https://github.com/nxp-mcuxpresso/sbl/blob/master/component/secure/semifunc/hab_rvt.c)
- [NXP SDP response definitions](https://spsdk.readthedocs.io/en/2.2.1/api/sdp.html)
- [NXP HAB RVT recommendations, AN12263](https://community.nxp.com/pwmxy87654/attachments/pwmxy87654/imx-processors/160465/2/AN12263.pdf)

The MIT license applies to original code and documentation authored for this
repository. It does not license Google/NXP firmware, third-party libraries or
materials linked above. Full firmware images, the extracted bootloader binary,
private device data and machine-specific paths are not included in the public
repository. Hashes, selected instruction evidence and sanitized measurements are
included. The controller used for the measurements is owned by the researcher.

## Español

Este proyecto se apoya en la investigación StadiaController de GaryOderNichts y
en el actualizador original de Google conservado por ChristopherKlay y
StadiaMemories. Los protocolos, métodos originales y constantes se atribuyen a
esos proyectos. Las nuevas herramientas se han escrito de forma independiente.

La licencia MIT cubre el código y la documentación originales de este repositorio.
No concede derechos sobre firmware de Google/NXP, bibliotecas de terceros o
materiales enlazados. La publicación incluye hashes, fragmentos de instrucciones
y mediciones sin identificadores personales. Las imágenes completas de firmware,
el binario extraído, los datos privados del mando y las rutas locales no se
publican. El mando empleado pertenece al investigador.
